# FIELDCORE — тактичний інтернет-магазин

Навчальний проєкт: адаптивний інтернет-магазин тактичного спорядження на чистих
HTML, CSS та JavaScript (без фреймворків і збірки).

> Це навчальний проєкт: оформлення замовлення та форма контактів **імітуються**,
> дані нікуди не надсилаються.

## Можливості

- Головна сторінка: hero, каталог, переваги, «Про нас», контакти, футер
- Каталог із **фільтрами за категорією**, **пошуком** та **сортуванням**
- **Сторінка товару** (`product.html?id=...`) з вибором розміру та схожими товарами
- **Кошик** у бічній панелі: кількість товарів (+ / −), видалення, підсумок,
  збереження в `localStorage` (кошик не втрачається після перезавантаження)
- **Оформлення замовлення** з перевіркою полів і екраном підтвердження
- Адаптивна верстка (телефон, планшет, ноутбук)
- Доступність: підпис кожного поля, керування з клавіатури, Esc закриває кошик,
  фокус не виходить за межі відкритого кошика, `prefers-reduced-motion`

## Структура проєкту

```
fieldcore/
├── index.html        головна сторінка
├── product.html      сторінка товару
├── style.css         усі стилі (із змістом у шапці файлу)
├── images/           фото
└── js/
    ├── ui.js         допоміжні функції (створення елементів, ціни, перевірка форм)
    ├── products.js   дані товарів і картка товару
    ├── cart.js       кошик: дані, збереження, панель, оформлення
    ├── main.js       логіка головної (каталог, фільтри, форма контактів)
    └── product.js    логіка сторінки товару
```

## Запуск

Збірка не потрібна: відкрийте `index.html` у браузері.
Для зручності можна запустити локальний сервер, наприклад командою
`python3 -m http.server` у папці проєкту, а потім відкрити `http://localhost:8000`.

## Як додати новий товар

1. Покладіть фото в папку `images/`.
2. Відкрийте `js/products.js` і скопіюйте будь-який блок `{ ... }` у списку `PRODUCTS`.
3. Змініть `id` (має бути унікальним), `sku`, назву, ціну, категорію та шлях до фото.

Каталог, сторінка товару та кошик підхоплять новий товар автоматично.

## Дані для демонстрації

Контакти, графік роботи й характеристики товарів — демонстраційні (телефон і
пошта вигадані). Змінити їх можна в `index.html` (блок «Контакти») та у
`js/products.js` (поле `specs` кожного товару).

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub (наприклад, `fieldcore`) і завантажте в нього вміст папки.
2. Відкрийте **Settings → Pages**.
3. У розділі **Build and deployment** оберіть **Deploy from a branch**,
   гілку `main` і папку `/ (root)`, натисніть **Save**.
4. За хвилину-дві сайт буде доступний за адресою
   `https://ВАШ-НІК.github.io/fieldcore/`.
